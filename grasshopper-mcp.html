Grasshopper MCP v2

Driving Grasshopper by conversation.

This open-source project enables language models to work directly with Rhino and Grasshopper, translating conversational instructions into visible and editable 3D modeling operations. It can inspect definitions, adjust parameters, connect components, troubleshoot workflows, and build new geometry. Powered by the Model Context Protocol (MCP), the system treats AI autonomy as a design variable through five Scenario modes: Inspect for read-only analysis, Tune for parameter changes, Coach for guided edits with explanations, Execute for running curated components and plugins, and Author for building definitions from scratch.
